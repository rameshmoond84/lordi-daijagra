# 🏛️ Lordi Daijagra - Panchayat Election War Room 2026

**ग्राम पंचायत लोरड़ी देजगरा (पंचायत समिति केरूं, 130-लूणी, जिला जोधपुर, राजस्थान)**  
सरपंच चुनाव 2026 हेतु डिजिटल मतदाता प्रबंधन एवं वॉर रूम प्रणाली।

---

## 🌟 मुख्य विशेषताएं (Key Features)

1. **कुल 2,673 मतदाता एवं 9 वार्ड:**
   - सभी 9 वार्डों का संपूर्ण प्रमाणित मतदाता डेटाबेस।
   - वार्ड-वार त्वरित फ़िल्टर एवं नेविगेशन।

2. **कुटुंब व परिवार-वार ग्रुपिंग (Family Cards):**
   - मकान नंबर आधारित परिवार कार्ड (एक ही मकान में अलग परिवारों हेतु `129A`, `129B` सब-डिवीजन सपोर्ट)।
   - परिवार के मुखिया (Head of Family) की पहचान।
   - **1-क्लिक फैमिली रुझान:** `[🟢 हमारा पक्का]`, `[🟡 संशय (मिलना है)]`, `[🔴 विरोधी]`।
   - **⚡ मुख्य निर्णयकर्ता (Key Decision Maker):** परिवार के मुख्य प्रभावशाली सदस्य की पहचान और सीधे कॉल की सुविधा।

3. **द्विभाषी खोज (Bilingual Phonetic Search):**
   - अंग्रेज़ी में टाइप करें (`baburam`, `indra`, `omaram`) या हिंदी में (`बाबूराम`, `इंद्रा`)।
   - मकान नंबर, फ़ोन नंबर या EPIC नंबर से तुरंत खोजें।

4. **बॉटम मोबाइल नेविगेशन (Mobile Bottom Nav):**
   - 🏠 **परिवार:** परिवार-वार कार्ड्स।
   - 👥 **सभी वोटर:** व्यक्तिगत मतदाता सूची एवं पर्ची।
   - ⭐ **प्रमुख वोटर:** 5+ सदस्य वाले बड़े परिवार, निर्णयकर्ता, 65+ बुजुर्ग, एवं प्रवासी।
   - 📊 **चुनावी गणित:** सरपंच जीत हेतु 950 वोटों का लक्ष्य, वार्ड 1 से 9 समीकरण, जातिगत समीकरण व आयु वर्ग।

5. **मतदाता पर्ची व व्हाट्सएप शेयरिंग:**
   - 1-क्लिक में औपचारिक मतदान पर्ची (Voter Slip) तैयार कर व्हाट्सएप पर भेजने की सुविधा।

6. **PWA (प्रोग्रेसिव वेब ऐप) सपोर्ट:**
   - **"लोरड़ी 0"** असली मील के पत्थर (Milestone) का उच्च-रिज़ॉल्यूशन ऐप आइकॉन।
   - किसी भी Android या iPhone पर बिना ऐप स्टोर के सीधे होमस्क्रीन पर इंस्टॉल करें।

## 🛠️ तकनीकी संरचना (Tech Stack)

* **Frontend:** HTML5, Tailwind CSS, Lucide Icons, Vanilla JavaScript.
* **Backend:** Node.js, Express.js.
* **Database:** Supabase (PostgreSQL) - Row Level Security, Indexed Search.
* **PWA:** Web App Manifest, Service Worker Caching, Native Install Prompt.

## 🚀 शुरू कैसे करें (Getting Started)

### 1. प्रोजेक्ट क्लोन करें:
```bash
git clone https://github.com/cityagency/lordi-daijagra.git
cd lordi-daijagra
```

### 2. डिपेंडेंसी इंस्टॉल करें:
```bash
npm install
```

### 3. एनवायरनमेंट कॉन्फ़िगर करें:
`.env.example` को `.env` के रूप में कॉपी करें और अपने Supabase क्रेडेंशियल्स दर्ज करें:
```env
PORT=3000
SUPABASE_URL=https://xobccfrgwnffsupjydmu.supabase.co
SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. सर्वर प्रारंभ करें:
```bash
node server.js
```
* कंप्यूटर पर खोलें: `http://localhost:3000`
* मोबाइल पर खोलें: `http://<your-local-ip>:3000`
